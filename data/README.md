# Dataset Instructions

This project uses the DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS
dataset.

Dataset:

https://data.mendeley.com/datasets/8gx2fvg2k6/1

DOI:

10.17632/8gx2fvg2k6

Download the dataset and place the required CSV file inside this directory.

The raw dataset is intentionally not committed to this repository. Please
refer to the dataset's licensing and usage conditions before redistributing
the data.
